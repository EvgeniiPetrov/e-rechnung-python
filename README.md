# E-Rechnung mit Python

**Ein Python-basiertes Werkzeug zur Erstellung, Verarbeitung und Validierung elektronischer Rechnungen in Deutschland.**

> 🚧 **Projektstatus:** In Entwicklung

## Über das Projekt

Dieses Projekt befindet sich in der Entwicklung.

Der Schwerpunkt liegt zunächst auf der Erstellung strukturierter XML-Rechnungen im Format **XRechnung (UBL)** sowie deren Validierung mit den offiziellen **KoSIT-Werkzeugen**.

## Geplante Funktionen

- **Rechnungserstellung:** Erstellung elektronischer Rechnungen aus strukturierten JSON-Daten
- **Datenprüfung:** Prüfung von Rechnungsdaten
- **XML-Export:** Export im XRechnung-Format
- **Validierung:** Validierung mit dem KoSIT-Validator
- **Geplante Erweiterungen:** Rechnungsimport und eine Weboberfläche

## Rechtlicher Hinweis

Dieses Projekt ist ein unabhängiges Lern- und Softwareprojekt. Es steht in keiner offiziellen Verbindung zur **KoSIT** oder zu deutschen Behörden.

Die Konformität der erzeugten Rechnungen mit dem Standard **XRechnung** wird im Rahmen der Entwicklung überprüft und ist derzeit **nicht gewährleistet**.
