# Назначение тестов

`test_smoke.py` и `test_cli.py` должны проходить сразу после установки пакета. Это **проверка каркаса**, а не подтверждение соответствия XRechnung.

Следующие тесты пользователь пишет сам после получения задач из `docs/05_SPRINT_00_AND_01.md`:
- `test_invoice_validation.py`;
- `test_invoice_calculations.py`;
- `test_ubl_invoice.py`;
- `test_kosit_adapter.py`.

Новые тесты вводить постепенно: сначала ожидаемое поведение, затем реализация. Не копировать будущий полный генератор из ИИ.
