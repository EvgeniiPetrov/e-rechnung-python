# KoSIT локальные компоненты

Здесь позже размещаются **скачанные самостоятельно** валидатор Java, конфигурация XRechnung и тестовые файлы.

Эта поставка **не включает** `jar`, набор схем, правила KoSIT и тестовую suite. Без них нельзя подтвердить полную совместимость XRechnung.

Порядок действий и официальные ссылки: `docs/09_KOSIT_VALIDATION.md`.
