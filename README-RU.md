# e-rechnung-python

**Приложение на Python для формирования и проверки структурированных электронных счетов в Германии.**

> **Статус:** в разработке. Генерация XRechnung XML и интеграция с KoSIT Validator пока не реализованы.

## Назначение

Проект **e-rechnung-python** предназначен для обработки структурированных данных счёта в формате **JSON**, формирования на их основе **XRechnung XML с синтаксисом UBL 2.1** и последующей проверки файлов инструментом **KoSIT Validator**.

## Планируемые возможности

- Чтение и проверка данных счёта из JSON
- Формирование электронных счетов в формате XRechnung (UBL 2.1)
- Валидация XML с помощью KoSIT Validator
- Сохранение выходных файлов и отчётов проверки
- В дальнейшем — импорт счетов и веб-интерфейс

## Текущее состояние

В репозитории подготовлены структура Python-пакета, базовый **CLI** (интерфейс командной строки) и первые автоматизированные тесты. Основная функциональность находится в разработке.

**Технологии:** Python 3.13+, XML, JSON, pytest, Ruff, uv.

## Быстрый запуск

Необходимы Python 3.13+ и [uv](https://docs.astral.sh/uv/). Выполнять из корня проекта:

```powershell
uv sync
uv run python -m e_rechnung --help
uv run pytest -q
```

## Структура проекта

```text
src/e_rechnung/    Python-пакет и CLI
  domain/          Модели данных и бизнес-правила (план)
  ubl/             Генерация XML (план)
  validation/      Интеграция с KoSIT (план)
tests/             Автоматизированные тесты
sample-data/       Искусственные тестовые данные
runtime/           Локальные входные и выходные файлы
                   (не предназначены для Git)
tools/kosit/       Локальные средства KoSIT (устанавливаются отдельно)
docs/              Техническая документация
```


## Ограничения

Проект **не связан официально** с KoSIT или государственными органами Германии. Соответствие создаваемых счетов требованиям XRechnung **пока не подтверждено**. Не размещайте в репозитории реальные счета, персональные данные и секреты доступа.
